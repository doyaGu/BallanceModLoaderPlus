# Internal documentation

These files describe BML+ maintenance, validation, and release procedures.
They are for repository maintainers and are not part of the public MkDocs sites
or SDK documentation.

- `release/`: release packaging and updater implementation notes.
- `scripting/`: script API coverage and validation records.
- `documentation/`: documentation build and deployment procedures.

Public prose belongs in `docs/en/` or `docs/zh-CN/`. Language-neutral,
downloadable API reference files belong in `docs/api/`.
