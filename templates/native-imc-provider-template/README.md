# __MOD_NAME__

This project is an `imc-provider` starter generated by BML+. Its API id is
`__IMC_API_ID__`; `api/service.imc` is the source of truth and the adjacent lock
file preserves assigned field numbers for compatibility checks.

Run the complete local loop with:

```bat
.\bml run
```

The first run asks for the two folders it needs and remembers them. Use the
commands below for CI or build troubleshooting.

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A Win32 `
  -DCMAKE_PREFIX_PATH="<BML-SDK>" `
  -DVIRTOOLS_SDK_PATH="<Virtools-SDK-2.1>" `
  -DCMAKE_INSTALL_PREFIX="<Ballance>/ModLoader"
cmake --build build --config RelWithDebInfo --target install
```

When intentionally changing the `.imc` schema, review and update its lock:

```powershell
cmake --build build --target bml_update_imc_locks
```

Commit the `.imc` file and `.imc.lock` together. The generated C++ header lives
in the build directory and must not be edited or committed. See
`share/BML/docs/en/imc-author-guide.md` for evolution rules and client examples.
