# BML+ Mod Templates

This directory contains author-facing starting points.

- `native-mod-template`: CMake-based native `.bmodp` mod template. Instantiate
  it with `scripts/New-BMLNativeMod.ps1`.
- `script-mod-template`: AngelScript `*.mod.as` script mod template.
  Instantiate it with `scripts/New-BMLScriptMod.ps1`.
