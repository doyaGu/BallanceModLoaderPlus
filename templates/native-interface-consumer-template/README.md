# __MOD_NAME__

This project is an `interface-consumer` starter generated by BML+. It declares
`__PROVIDER_ID__` as a required Mod dependency and links only the independent
header package `__PROVIDER_PACKAGE__::Interface`, never the provider DLL.

If the provider has already been deployed to the same Ballance installation,
one command finds its installed package, builds this consumer, deploys it, and
starts Player:

```bat
.\bml run
```

The first run asks for the two folders it needs and remembers them. Use the
commands below for CI or build troubleshooting.

Install the matching provider package first, then configure this project with
both package roots:

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A Win32 `
  -DCMAKE_PREFIX_PATH="<BML-SDK>;<provider-package>" `
  -DVIRTOOLS_SDK_PATH="<Virtools-SDK-2.1>" `
  -DCMAKE_INSTALL_PREFIX="<Ballance>/ModLoader"
cmake --build build --config RelWithDebInfo --target install
```

The sample reads `35` through the provider and logs `42`. Replace the sample call
with your real interface methods. Keep the `RequiredInterface` member alive until
`OnUnload`, and do not cache the provider pointer beyond that dependency lifetime.
